How the RAG Pipeline Works
When the LLM generates an explanation for a fraud alert, it first retrieves the most relevant fraud patterns from this knowledge base via semantic vector search (pgvector + HNSW). These patterns are injected into the prompt as expert context, helping the model produce accurate, regulation-grounded explanations instead of hallucinating generic risk language.

Detection Rule Thresholds
Used by RULES_ONLY, FULL_SYSTEM
Transparency note for thesis reviewers. Rule-based AML systems use numeric thresholds that vary widely across deployments. The values below are thesis-calibrated defaults — chosen so the RULES_ONLY baseline flags ~1–5 % of transactions on PaySim, matching the industry-reported false-positive range (Gartner 2021; ACAMS 2022). The paper defaults and published industry range are shown side-by-side so you can verify the calibration, and every threshold is editable in case you want to explore a different operating point. See §4.5 of the thesis for the full calibration methodology.
