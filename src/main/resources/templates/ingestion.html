Feature Engineering

Computes ML input features for every imported transaction that has not been processed yet. Features include z-scores, velocity counts (1h/24h), receiver diversity, balance ratios, and more. Run this manually after importing to prepare transactions for fraud detection. Safe to re-run — already processed rows are skipped.
