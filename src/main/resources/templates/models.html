What Will Be Trained
Random Forest
Pure Java · Tribuo 4.3

Ensemble of 100 decision trees. Each tree is trained on a random subset of features (√13 ≈ 3–4 per split). Final prediction is a majority vote — robust to noise and rarely overfits.

No native deps Stable Fast inference
XGBoost
Gradient Boosting · JNI

100 boosted trees trained sequentially — each one corrects the residual errors of the previous. State-of-the-art on tabular data. Requires the native XGBoost JNI library.

High accuracy Needs JNI Boosted
Ensemble mode (default): both models score each transaction independently. The higher fraud probability wins — a conservative, high-recall approach that minimises missed fraud.
Train Models
What happens when you click Train
1 Load training data — all transactions that have computed features are streamed in batches. Transactions without features are skipped.
2 Train Random Forest — 100 CART trees on a feature-subset of the dataset. Labels: FRAUD vs LEGIT. Pure Java, always succeeds.
3 Train XGBoost — 100 gradient-boosted trees via JNI. If the native library is unavailable on your OS, this stage is skipped gracefully.
4 Save to disk — serialized model files written to data/models/. Auto-loaded on next application restart.
3–10 min · RF runs in parallel mini-forests
Load Saved Models
Load previously trained models from data/models/ on disk. Useful after a server restart — avoids re-training from scratch. Models are automatically saved to disk after each training run.
